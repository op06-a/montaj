1. Что такое материнская плата

Материнская плата — основная печатная плата ПК, связывающая все компоненты.

  • Сокет CPU — разъём для процессора.
  • Слоты DIMM — для оперативной памяти (DDR5).
  • Чипсет — коммутатор периферии: SATA, USB, часть PCIe, аудио, сеть.
  • VRM — стабилизатор питания процессора.
  • PCIe x16 — слот для видеокарты.
  • M.2, SATA — для накопителей.
  • 24-pin ATX, 8-pin EPS — разъёмы питания.
  • F_PANEL — колодка передней панели.

2. Архитектура

  • Напрямую к CPU: RAM и PCIe x16 (видеокарта).
  • Через чипсет: SATA, USB, M.2, аудио, сеть.

3. Путь сигнала (кратко)

  • Power SW → чипсет → PS_ON → БП → питание → CPU → BIOS → POST → загрузчик ОС.

Подробно — на этапе 7 «Сигналы».

4. Кабели и разъёмы

  • 24-pin ATX — основное питание платы.
  • 8-pin EPS — питание CPU.
  • 6+2-pin PCIe — питание видеокарты.
  • SATA power и SATA data — для HDD/SSD.
  • F_PANEL — Power SW, Reset SW, HDD LED, Power LED, Speaker.
  • F_USB3 (19-pin), F_USB (9-pin), F_AUDIO (9-pin), F_U32C.

5. Типичные ошибки

  • Плата без стоек — КЗ.
  • Винты по кругу — перекос.
  • Нет 8-pin CPU — нет изображения.
  • DDR4 в DDR5 — не подходит.
