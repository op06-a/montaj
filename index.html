1. Что такое материнская плата

Материнская плата (motherboard) — основная печатная плата ПК, связывающая все компоненты в единую систему.

  • Сокет CPU — разъём для процессора (AM5, LGA1700 и др.).
  • Слоты DIMM — для оперативной памяти (DDR5 на современных платах).
  • Чипсет — коммутатор периферии: SATA, USB, часть PCIe, аудио, сеть.
  • VRM — модуль стабилизации питания процессора.
  • PCIe — для видеокарты (x16) и плат расширения.
  • M.2 и SATA — для накопителей.
  • Разъёмы питания: 24-pin ATX и 8-pin EPS.
  • F_PANEL — колодка для кнопок и индикаторов передней панели.

2. Архитектура

  • Напрямую к CPU: оперативная память и основной PCIe x16 (видеокарта).
  • Через чипсет: SATA, USB, часть PCIe, M.2, аудио, сеть.

3. Путь сигнала

  • Power SW — замыкается контакт на F_PANEL.
  • Супервизор/чипсет проверяет напряжения БП, даёт команду PS_ON.
  • БП подаёт питание через 24-pin и 8-pin.
  • CPU запускает BIOS/UEFI, проходит POST.
  • Поиск загрузчика и передача управления ОС.

Условие работы: без CPU, RAM, видеокарты, 24-pin, 8-pin и Power SW — POST не пройдёт.

4. Типичные ошибки монтажа

  • Установка платы без стоек — короткое замыкание.
  • Винты по кругу — перекос платы. Правильно — крест-накрест.
  • Нет 8-pin CPU — ПК включается, но нет изображения.
  • Неправильная установка Power SW — кнопка не работает.
  • DDR4 в слоте DDR5 — ключ не совпадает.
